# Лабораторная работа №2
## Генетический алгоритм для плана дежурств на неделю

**Вариант:** 10  
**Задача:** Составление плана дежурств на неделю с ограничениями по сменам  
**Группа:** Б24-517, № в группе 28

## Постановка задачи
Требуется составить расписание дежурств для 25 сотрудников на 7 дней (3 смены: утро, день, ночь), удовлетворяющее строгим ограничениям и минимизирующее мягкие штрафы.

## Представление решения
Особь представляет собой бинарную матрицу `X` размером `25 × 21`, где `X[i, j] = 1`, если сотрудник `i` работает в слоте `j` (день `d`, смена `s`, где `j = d*3 + s`), и `0` в противном случае.

## Ограничения
**Жёсткие (штраф 1000):**
1. Минимум 3 человека на каждом из 21 слота.
2. Максимум 5 смен на одного сотрудника в неделю.
3. Запрет работы в ночную смену с последующей утренней (минимум 14 часов отдыха).
4. Каждый сотрудник должен иметь минимум 1 полный выходной день.
5. Только старшие сотрудники (5 чел.) могут работать в ночную смену.

**Мягкие (штраф 10):**
6. Равномерность нагрузки (минимизация дисперсии числа смен).
7. Учёт предпочтений сотрудников к типам смен.

## Операторы алгоритма
- **Инициализация:** случайное назначение с учётом квалификации и гарантии выходного.
- **Кроссовер:** равномерный по строкам (сотрудникам), сохраняет целостность расписания каждого человека.
- **Мутация:** случайное переназначение `n` слотов у случайного сотрудника с проверкой допустимых смен.
- **Ремонт (Repair):** детерминированная процедура исправления нарушений жёстких ограничений после вариации.
